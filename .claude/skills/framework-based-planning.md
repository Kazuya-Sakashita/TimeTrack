# Framework-Based Planning Skill

Claude Code は、計画・判断・評価を行う前に、目的に合ったフレームワークを選択する。

## 基本方針

フレームワークは、見た目を整えるためではなく、判断根拠を明確にするために使う。

## 選択ルール

- 実装計画を立てる → MVP / MoSCoW / RICE
- Issue を分割する → INVEST / Vertical Slice
- 優先順位を決める → RICE / ICE / Impact Effort Matrix
- UIを改善する → G-STACK / HEART / Nielsen
- APIを設計する → API First / Contract First
- DBを設計する → 正規化 / DDD Lite
- セキュリティを見る → OWASP Top 10 / STRIDE
- テストを考える → テストピラミッド / リスクベーステスト
- ブログを書く → PREP / 課題→解決→学び

## 出力ルール

計画・判断・評価を含む出力では、必ず以下を含める。

- 使用したフレームワーク
- 採用理由
- 評価結果
- 計画
- 優先順位
- 次のアクション
